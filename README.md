# cut-long-task · 长任务分段

为长任务预留五小时额度。只需给出**具体时间点**，或**额度刷新后几分钟**，技能负责保存进度、暂停和后续恢复，默认保留 **20%**。

## 一句话安装

把下面这句话粘贴给支持 Codex 技能安装的智能体：

```text
$skill-installer 请从 https://github.com/jeffinchina/cut-long-task/tree/main/skills/cut-long-task 安装 cut-long-task（长任务分段）技能。
```

已安装旧版时，请让智能体将此技能更新为同一地址的最新版本。

## 两种最简用法

固定时间点（一个或多个）：

```text
$cut-long-task 今晚21:00、明天09:00
```

额度刷新后延迟：

```text
$cut-long-task 额度刷新后7分钟
```

第二种默认按真实额度刷新逐轮续接到任务完成、取消或需要人工处理的真实阻塞，不必再写“每次”、读取接口、复用检查点、唯一节点或持续续建等细节。需要限制期限时可附“直到11月2日全天结束”；写“仅本次”才只安排一次。续用已有任务时，其仍有效的旧截止限制继续有效。

要保留其他比例，只需追加百分比或0–1小数：

```text
$cut-long-task 额度刷新后7分钟，15%
```

`20%` 与 `0.2` 等价；省略比例默认20%。绑定本对话当前任务，也可附在新任务后：

```text
完成这份报告并核验数据。$cut-long-task 额度刷新后7分钟
```

默认立即推进；“到点再开始”才延迟启动。完成后的检查静默，不重复工作。

## 技能内置的工作流

- 每段工作前后读取适用五小时的真实剩余额度，剩余量大于保留比例才继续；达到保留线就保存成果、已有测试证据和下一步，暂停本任务派生代理。
- 固定时点仅使用输入的时间表；刷新模式每轮读取真实 `resetsAt` 加指定延迟，只维护一个未来恢复节点，忙碌时也不丢掉后继。不会按固定五小时推算后面的刷新时间。
- 复用同任务的检查点，按新参数维护本对话本任务的技能节点，保留现有审批策略；其他任务、对话和项目不动。
- 读取失败、计划创建失败、审批或其他硬限制分别报告，不声称安排成功。任务完成、取消、授权撤销、期限到达或需要人工处理时停止相应续建。

## 运行条件

需要支持真实五小时额度读取和当前对话定时任务的环境，例如具备相应工具的 Codex 桌面端。本地恢复需要电脑在线且客户端运行；安装或修改技能本身不启动任何工程或自动化。

额度由同账号任务共享。技能在工作单元之间主动节制，无法保证精确锁定保留比例，也不能在不可中断操作中实时卡点；不会变更模型、套餐、购买额度、消耗重置券或修改审批策略。

技能位于 [skills/cut-long-task](skills/cut-long-task)，中文显示名“长任务分段”，英文标识 `cut-long-task`。无需安装 `task-finish-clock`。
