# cut-long-task · 长任务分段

为长任务预留一部分账号五小时额度：剩余额度达到指定比例时保存进度并主动暂停，在用户给出的下一个时间点重新检查额度后续做。默认保留 **20%**。

## 一句话安装

把下面这句话粘贴给支持安装 Codex 技能的智能体：

```text
$skill-installer 请从 https://github.com/jeffinchina/cut-long-task/tree/main/skills/cut-long-task 安装 cut-long-task（长任务分段）技能。
```

## 使用

附在长任务后，或在同一对话中单独调用：

```text
把这份长报告整理成最终稿并完成核验。$cut-long-task 今晚21:00、明天09:00，保留20%
```

```text
$cut-long-task 今晚21:00、明天09:00，0.3
```

```text
$cut-long-task 今晚21:00、明天09:00
```

`20%` 与 `0.2` 等价；不填写比例时默认保留 20%。时间点至少一个，比例表示**剩余额度**，而非已用额度。

- 默认立即推进，同时尽早建立当前对话内的一次性恢复计划。明确要求“到点再开始”时才延迟启动。
- 每个工作单元前后读取真实额度。剩余额度小于或等于保留比例时保存检查点、停止新工作并暂停本任务派生代理。
- 到指定时间，额度高于保留比例才续做；仍不足则等后续已指定时间点。没有后续时间点时提醒补充，不自行增加计划。
- 任务已经完成时，后续检查静默，不重复执行。

## 运行条件与边界

需要能读取真实五小时额度、并能创建当前对话内定时恢复任务的环境，例如具备相应工具的 Codex 桌面端。安装技能本身不会创建定时任务；实际调用时才根据时间点创建。

额度是账号共享的。技能通过工作单元边界的检查主动节制，不是服务端硬限额；其他并行任务、收尾及两次观测之间的工作仍会耗用额度，无法保证精确锁定保留比例。额度不可验证时保存进度并保持暂停，不静默降级为无限制执行。

本地定时恢复需要电脑在线、客户端保持运行。技能自包含，无需另行安装 `task-finish-clock`，不包含任何账号凭据或本机私密配置。
